Sunset Cover Studio turns your photos into neon sunset posters in your browser. Choose from four panel layouts, position and rotate each crop, add a title and subtitle, and tune the color grade. Open app/index.html in desktop Chrome to work offline and export a full-resolution PNG in landscape, portrait, or square format.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
